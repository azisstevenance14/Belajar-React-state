# 🚀 Belajar React & Interaktif State (Katalog Produk Digital)

Proyek latihan interaktif berbasis Single-Page Application (SPA) menggunakan **React.js** dan **Vite**, yang dikembangkan untuk memahami konsep fundamental frontend modern seperti **Componentization, Props, Array Mapping (`.map()`), dan State Management (`useState`)**.

---

## 🛠️ Teknologi yang Digunakan
* **React.js** (Library UI berbasis komponen)
* **Vite** (Frontend Build Tool super cepat)
* **JavaScript (ES6+)**
* **HTML5 & CSS3 / Inline Styles**
* **Git & GitHub** (Version Control)

---

## 💡 Fitur Utama & Konsep yang Dipelajari
1. **Dynamic Rendering (`.map()`):** Mengonversi data *array of objects* secara otomatis menjadi elemen tampilan UI tanpa *hardcode* HTML manual.
2. **Props Flow:** Mengirim data dinamis dari komponen utama (`App`) ke komponen anak (`KartuProduk`).
3. **Local State (`useState`):** Mengelola memori internal komponen secara independen (contoh: fitur tombol interaktif *Like Counter* per kartu produk).
